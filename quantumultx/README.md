# Quantumult X

存放 Quantumult X 使用的分流规则、重写规则、脚本和配置片段。

## 子目录

- `configs/`: Quantumult X 配置片段或完整配置。
- `filters/`: 分流规则。
- `rewrites/`: 重写规则。
- `scripts/`: 重写规则或任务引用的脚本。

## 文件建议

- 分流规则常用 `.list` 后缀。
- 重写规则可使用 `.conf` 或 `.rewrite` 后缀。
- 脚本按语言使用 `.js` 等后缀。

## 已收录规则

- `filters/binance.list`: Binance App 分流规则，基于 iOS App 抓包整理。
